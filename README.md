# Dashboard Financeiro Pessoal

Um dashboard completo para controle financeiro pessoal com funcionalidades avançadas.

## 🚀 Funcionalidades

### ✅ Funcionalidades Implementadas

- **📊 Dashboard Interativo**: Visualização de receitas, despesas e saldo em tempo real
- **👤 Autenticação de Usuários**: Sistema de login e cadastro seguro
- **🎯 Metas Financeiras**: Definir e acompanhar objetivos financeiros
- **🏦 Integração com APIs de Bancos**: Conectar contas bancárias (simulado)
- **📄 Relatórios PDF**: Exportar análises financeiras em PDF
- **🌓 Modo Escuro/Claro**: Interface alternável entre temas
- **📤 Exportação de Dados**: Exportar para CSV, Excel e JSON
- **📱 Design Responsivo**: Interface adaptável para diferentes dispositivos
- **🎨 Gráficos Interativos**: Visualizações com Plotly
- **💾 Banco de Dados SQLite**: Armazenamento persistente
- **🚀 Deploy na Nuvem**: AWS EC2 e Render

### 🛠️ Tecnologias Utilizadas

- **Backend**: Python, Dash, Flask
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap
- **Banco de Dados**: SQLite
- **Gráficos**: Plotly
- **Relatórios**: ReportLab
- **Deploy**: AWS EC2, Render, Docker
- **Controle de Versão**: Git, GitHub
